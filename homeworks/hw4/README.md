##NV_bioing_utils

###Основные возможности

- Фильтрация FASTQ: Отбор чтений по пороговому качеству (Phred33), диапазону длины и проценту GC-состава.
- Линеаризация FASTA: Преобразование многострочных файлов FASTA в однострочные.
- Парсинг BLAST: Извлечение лучших совпадений из результатов BLAST с алфавитной сортировкой

###Требования
- работает на python 3.11

###
Основные функции:

1. Фильтрация FASTQ файлов (filter_fastq): 
Функция отбирает чтения, проходящие фильтры по качеству, длине и GC-составу, и сохраняет их в отдельную папку filtered/

2. Конвертация многострочного FASTA в однострочный (convert_multiline_fasta_to_oneline):
Разворачивает последовательность нуклеотидов или аминокислот, разбитую на несколько строк, в одну сплошную строку для каждого заголовка

3. Парсинг результатов BLAST (parse_blast_result):
Извлекает первые строки из таблицы описаний результатов BLAST для каждого запроса, сортирует их по алфавиту и сохраняет в новый файл.
